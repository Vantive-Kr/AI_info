문제 해결

막혔을 때 어떻게 하나요?

에러 코드가 아예 작동을 안 해요 +
먼저 브라우저 개발자 도구를 열어서 에러 메시지를 확인하세요 (F12 → Console 탭). 에러 메시지가 빨간색으로 나타납니다. 그 내용을 그대로 복사해서 Claude에게 보여주세요.
"F12 눌러서 Console에 나온 빨간 글자 복사 → Claude에 붙여넣기"
결과 원하는 디자인이 안 나와요 +
너무 추상적으로 설명했을 가능성이 높아요. "예쁘게"보다는 "파란색 배경에 흰 글씨, 버튼은 둥근 모서리 처리"처럼 구체적으로 설명하세요. 참고 사이트 URL을 공유하는 것도 좋은 방법이에요.
"'네이버 홈페이지처럼' 또는 구체적인 색상 코드, 크기 포함해서 다시 요청"
코드 코드가 너무 길어서 어디서 복사해야 할지 모르겠어요 +
Claude에게 "HTML 파일 하나로 만들어줘"라고 명시적으로 요청하면 ```html로 시작하는 코드 블록 하나가 나와요. 해당 블록 전체를 복사해서 메모장에 붙여넣고 .html 확장자로 저장하면 됩니다.
"'단일 HTML 파일 하나로만 만들어줘'라고 조건 추가하기"
활용 만든 걸 다른 사람에게 보여주고 싶어요 +
HTML 파일을 공유하는 가장 쉬운 방법은 이메일 첨부나 구글 드라이브 공유입니다. 온라인에 올리고 싶다면 GitHub Pages나 Netlify Drop (netlify.com/drop)에 파일을 드래그하면 무료로 URL을 얻을 수 있어요.
"netlify.com/drop 에 .html 파일 드래그 → 즉시 공유 URL 생성"
막힘 Claude가 계속 엉뚱한 걸 만들어줘요 +
새 대화를 시작하고, 처음부터 더 상세한 요구사항을 적어보세요. "이것과 비슷하게"라는 표현보다는 기능, 레이아웃, 색상을 목록으로 적어서 요청하는 게 효과적이에요.
"새 대화 시작 + 요구사항을 번호로 나열해서 명확하게 작성"
