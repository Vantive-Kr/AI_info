보안 구조 설정

Vantive_Techwiki_index_pw.html 에 적용된 3가지 보안 레이어

① SHA-256 비밀번호 암호화
실제 비밀번호 문자열이 파일에 저장되지 않습니다. 비밀번호의 해시값만 코드에 존재하므로, 파일이 노출되더라도 원래 비밀번호를 알 수 없습니다.
WebCrypto API
② 5회 실패 잠금 시스템
비밀번호를 5회 연속 틀리면 15분간 로그인이 잠깁니다. 잠금 상태는 페이지를 새로고침해도 유지되며, 카운트다운 타이머가 표시됩니다.
localStorage 기반
③ 8시간 세션 자동 만료
로그인 후 8시간이 경과하면 자동으로 세션이 만료되어 재로그인이 필요합니다. 브라우저 탭을 닫으면 즉시 세션이 종료됩니다.
sessionStorage 기반

💡
보안 수준 안내
이 구조는 내부 팀 전용 도구에 적합한 클라이언트 사이드 보안입니다. 브라우저 개발자 도구로 우회 가능하지만, 내부 직원 대상으로는 충분한 접근 제어 효과가 있습니다.

비밀번호 변경 방법

새 비밀번호 설정 — 3단계로 완료

1
SHA256 도구에서 해시값 생성
아래 링크의 온라인 도구에서 새 비밀번호를 Input 칸에 직접 타이핑합니다.
Auto Update가 켜져 있으면 Output에 즉시 해시값이 표시됩니다.
emn178.github.io/online-tools/sha256.html
Input Encoding : UTF-8 (기본값 유지) Output Encoding : Hex (Lower Case) (기본값 유지) Enable HMAC : OFF (기본값 유지) ⚠️ Enter 키 누르지 말 것 → 줄바꿈(\n)이 포함되어 해시값이 달라짐 ⚠️ Input 앞뒤 공백 없도록 확인 (복사 붙여넣기 주의)
2
Output 해시값 전체 복사
Output 칸의 64자리 16진수 문자열을 전체 선택 후 복사합니다.
예시 — 787a126e8ce277e9a07b2d2fb6e14064e850933b8627...
⚠️
주의: 같은 비밀번호인데 해시가 다르게 나온다면?
Input 칸에 줄바꿈 문자(\n)나 앞뒤 공백이 포함된 것입니다. Input 칸을 완전히 지우고 비밀번호를 다시 직접 타이핑하세요.
3
HTML 파일에서 CORRECT_HASH 교체
Vantive_Techwiki_index_pw.html을 텍스트 에디터로 열고, 아래 줄을 찾아 작은따옴표 안의 값만 교체합니다.
// 🔍 이 줄을 찾아서 const CORRECT_HASH = '3117f7aab1d822bef0c6e408c474112e9c276c620d9b36309645e5e23e6d384a'; // ✏️ 새 해시값으로 교체 const CORRECT_HASH = '여기에_새_해시값_붙여넣기_64자_전체';
✅
저장 후 즉시 적용
파일을 저장하면 완료입니다. GitHub에 올린 경우 브라우저 강제 새로고침(Ctrl+Shift+R) 후 5분 내외 대기 후 테스트하세요.
3

공지 팝업 설정

로그인 성공 후 표시되는 공지 팝업 — 4개의 설정값만 수정하면 됩니다

수정 가능한 설정값 (HTML 파일 최상단)
NOTICE_ENABLED boolean
팝업을 표시할지 말지를 결정합니다.
true = 팝업 표시 / false = 완전히 숨김
// 팝업 켜기 const NOTICE_ENABLED = true; // 팝업 끄기 const NOTICE_ENABLED = false;
NOTICE_UNTIL string (날짜)
이 날짜까지만 팝업을 표시합니다.
날짜가 지나면 자동으로 팝업이 사라집니다. 계속 표시하려면 먼 미래 날짜로 설정하세요.
// 2026년 6월 30일까지 const NOTICE_UNTIL = '2026-06-30'; // 무기한 표시 const NOTICE_UNTIL = '2099-12-31';
NOTICE_TITLE string
팝업 상단에 표시될 제목입니다.
이모지를 포함해도 됩니다.
const NOTICE_TITLE = '🔒 보안 업데이트 안내'; const NOTICE_TITLE = '📢 3월 정기 점검 공지';
NOTICE_BODY HTML string
팝업 본문입니다. HTML 태그 사용 가능합니다.
백틱(`) 사이에 내용을 작성하세요.
const NOTICE_BODY = ` <p>공지 내용을 입력하세요.</p> <ul> <li>항목 1</li> <li>항목 2</li> </ul> `;

공지 팝업 설정 블록 찾기

/* ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ * 📢 공지 팝업 설정 ← 여기만 수정하세요 * ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ */ const NOTICE_ENABLED = true; const NOTICE_UNTIL = '2026-06-30'; const NOTICE_TITLE = '🔒 보안 업데이트 안내'; const NOTICE_BODY = ` <p>내용 입력</p> `;
3
저장 후 업로드
파일을 저장하고 GitHub에 업로드하면 즉시 반영됩니다.
팝업을 내리고 싶을 때는 NOTICE_ENABLED = false 로 변경하거나 NOTICE_UNTIL의 날짜를 오늘보다 이전 날짜로 설정하세요.
ℹ️
"오늘 하루 보지 않기" 기능
사용자가 팝업에서 "오늘 하루 보지 않기"를 체크하면 해당 브라우저에서 당일 재접속 시 팝업이 표시되지 않습니다. 다음 날 자정이 지나면 자동으로 초기화됩니다.
✓

전체 요약

수정 가능한 모든 설정값 한눈에 보기

설정값 기본값 역할 구분
CORRECT_HASH 3117f7aa... 비밀번호 SHA-256 해시값 (원문: Vantive2025) 보안
MAX_ATTEMPTS 5 로그인 최대 실패 허용 횟수 보안
LOCK_MS 15분 실패 초과 후 잠금 지속 시간 보안
SESSION_MS 8시간 로그인 세션 유지 시간 보안
NOTICE_ENABLED true 공지 팝업 표시 여부 (true/false) 공지
NOTICE_UNTIL '2026-06-30' 팝업 자동 만료 날짜 (YYYY-MM-DD) 공지
NOTICE_TITLE '🔒 보안 업데이트...' 팝업 헤더에 표시될 제목 공지
NOTICE_BODY HTML 템플릿 팝업 본문 내용 (HTML 태그 가능) 공지
🔑
비밀번호 변경 원칙
절대 원본 비밀번호를 파일에 직접 쓰지 마세요.
반드시 SHA256 도구에서 해시값으로 변환한 후, CORRECT_HASH 값만 교체합니다.
새 비밀번호 입력 시 Enter를 누르지 말고, 복사할 때 앞뒤 공백이 포함되지 않도록 주의하세요.
