개념 이해

MCP를 한마디로?

MCP(Model Context Protocol)는 AI가 이메일·파일·데이터베이스 등 외부 도구를 사용할 수 있게 해주는 표준 규격입니다.
Anthropic이 2024년 발표했으며, Claude뿐 아니라 모든 AI가 사용할 수 있는 오픈 표준입니다.

비유 ①
USB 허브

USB 포트 하나의 규격을 따르면 마우스·키보드·저장소 모두 연결되듯, MCP 표준 하나로 Gmail·Slack·Notion 등 어떤 서비스든 AI와 연결됩니다.

비유 ②
통역사

Claude(AI)는 한국어만 하고, Gmail은 영어만 하는 상황. MCP는 이 둘 사이에서 서로 통할 수 있도록 표준화된 말을 번역해주는 통역사 역할을 합니다.

비유 ③
표준 콘센트

220V 콘센트 규격이 있으면 어떤 가전이든 꽂아 쓸 수 있듯, MCP라는 표준이 있으면 어떤 서비스든 AI에 "꽂아서" 바로 사용할 수 있습니다.

비교

MCP 이전 vs 이후

MCP가 없으면 AI는 대화만 할 수 있습니다. MCP가 있으면 AI가 실제로 움직입니다.

❌ MCP 없을 때
AI는 대화 상자에 갇혀 있음
"이메일 보내줘" → 불가능. 대신 본문을 알려줄 뿐, 실제 발송은 사용자가 직접
"이번 주 캘린더 확인해줘" → 불가능. AI는 사용자 일정을 볼 수 없음
"Notion에 정리해줘" → 불가능. AI는 외부 앱에 접근 불가
모든 실제 행동은 사용자가 복사-붙여넣기로 직접 처리

✅ MCP 있을 때

"이메일 보내줘" → 바로 발송 완료. Claude가 Outlook에 직접 접속해 전송
"이번 주 캘린더 확인해줘" → 일정 읽어서 요약. 오늘 미팅 3개 있다고 바로 알려줌
"Notion에 정리해줘" → 직접 작성 완료. 새 페이지 생성 후 내용 입력까지

실전 사용

Claude에서 MCP 연결하기

Claude Cowork에서는 GUI로 간단하게 MCP를 연결합니다. 코딩 없이 몇 번의 클릭으로 완료됩니다.

1
Cowork 설정 열기
Claude Cowork 앱 → 상단 톱니바퀴(⚙️) 클릭 → Connectors 탭 선택
2
원하는 서비스 선택
Gmail, Outlook, Slack, Notion 등 연결할 서비스를 목록에서 클릭
3
OAuth 로그인으로 인증
브라우저가 열리면 해당 서비스 계정으로 로그인 → "허용" 버튼 클릭
4
Claude에게 명령하기
이제 "Gmail에서 오늘 받은 이메일 요약해줘"처럼 자연어로 사용 가능

💬 연결 후 사용 예시

"오늘 Gmail 미읽은 메일 중에 중요한 거 3개만 요약해줘"
"이번 주 월요일 오전 10시에 팀 미팅 캘린더에 추가해줘"
"Slack #general 채널에 오늘 회의 결과 요약 메시지 보내줘"
보안 걱정되시나요?
MCP는 OAuth 2.0 표준 인증을 사용합니다. Claude가 비밀번호를 저장하지 않으며, 언제든지 연결을 해제할 수 있습니다.
고급 설정

직접 설정하려면? (선택 사항)

GUI로 안 되는 사내 시스템 등을 연결할 때는 JSON 설정 파일로 MCP 서버를 추가합니다. 처음에는 복사-붙여넣기만 해도 됩니다.

plugin.json — MCP 서버 추가
// plugin.json 파일 내 mcpServers 항목 "mcpServers": { // Gmail 연결 예시 "gmail": { "command": "npx", "args": ["-y", "@anthropic/mcp-server-gmail"], "env": { "GMAIL_OAUTH_TOKEN": "발급받은_토큰" } }, // 파일 시스템 연결 예시 "filesystem": { "command": "npx", "args": [ "-y", "@anthropic/mcp-server-filesystem", "/Users/내이름/Documents" // 접근 허용 폴더 ] } }

📋 설정 순서

1. Node.js 설치 (nodejs.org — 무료)
2. MCP 서버 패키지 이름 확인 (GitHub 페이지 참조)
3. plugin.json에 위 형식으로 복사-붙여넣기
4. Claude 재시작 → 연결 확인
초보자 팁
처음에는 GitHub에서 공식 서버의 README를 찾아 예시 설정을 그대로 복사하세요. Claude에게 "이 MCP 서버 설정 방법 알려줘"라고 물어봐도 됩니다.

초보자 FAQ

🤔 MCP와 API는 다른 건가요?
API는 서비스마다 규격이 달라 개발자가 각각 코드를 짜야 했습니다. MCP는 그 위에 공통 표준 레이어를 씌운 것입니다. AI 관점에서 보면 API는 서비스마다 다른 방언, MCP는 모두가 쓰는 표준어라고 볼 수 있습니다.
💰 MCP 사용이 유료인가요?
MCP 표준 자체는 완전 무료 오픈소스입니다. 단, MCP를 통해 연결하는 서비스(Gmail, Slack 등)의 API 사용량에 따라 해당 서비스 요금이 발생할 수 있습니다. 대부분의 일반적인 사용량에서는 무료 범위 내에 들어옵니다.
🔐 내 이메일이나 파일이 유출되지 않나요?
MCP는 AI가 요청한 작업에 필요한 데이터만 가져오는 구조입니다. 사용자가 명령하지 않은 데이터에 임의로 접근하지 않습니다. 또한 OAuth 인증을 통해 허용한 범위 내에서만 동작하며, 언제든지 연결을 끊을 수 있습니다.
🛠️ MCP 서버를 직접 만들 수 있나요?
네, 가능합니다. Python 또는 TypeScript/Node.js로 만들 수 있습니다. Anthropic이 공식 SDK를 제공하며, 기존 MCP 서버 코드를 참고하면 초보자도 도전해볼 수 있습니다. 사내 전용 시스템(ERP, 사내망 DB 등)을 연결하려면 직접 제작이 필요합니다.
🌍 Claude 말고 다른 AI도 MCP를 쓸 수 있나요?
네! MCP는 오픈 표준이라 어떤 AI도 사용할 수 있습니다. 현재 GitHub Copilot(VS Code), Cursor, Windsurf 등 주요 AI 코딩 도구들도 MCP를 지원하기 시작했습니다. 한 번 만든 MCP 서버를 여러 AI 앱에서 재사용할 수 있습니다.
