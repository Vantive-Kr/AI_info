개념 이해

바이브 코딩이란?

"코딩을 몰라도 AI와 대화하듯 원하는 것을 설명하면 코드가 만들어지는 방식"입니다. 2025년 Andrej Karpathy(전 Tesla AI 총괄)가 처음 제안한 개념으로, AI 시대의 새로운 개발 패러다임입니다.

💬

생성

수정

Claude vs GitHub Copilot

둘 다 AI 코딩 도구지만 사용 환경과 방식이 다릅니다. 목적에 따라 선택하세요.

Claude Cowork
채팅 → 파일 생성
설치 없이 브라우저 또는 데스크톱 앱에서 바로 사용
파일을 직접 열고, 수정하고, 저장까지 한번에 처리
스킬·커넥터로 이메일 발송, Excel 처리 등 업무 자동화 연계
코드 에디터(VS Code) 통합 없음 — 에디터 내 자동완성 미지원
대규모 코드베이스 전체 탐색은 제한적
VS
GitHub Copilot
VS Code 에디터 내 AI
VS Code 에디터 안에서 직접 코드 자동완성 및 채팅
열린 파일 전체를 컨텍스트로 참조하여 정확도 향상
GitHub 무료 계정으로 월 2,000회 자동완성 무료 제공
VS Code 설치 필요 — 완전 초보자에게 환경 설정이 허들
파일 저장·실행·업무 연동은 사용자가 직접 처리
💡

언제 무엇을 쓸까?

Claude Cowork — 설치 없이 바로, 업무 파일 처리·자동화까지 한번에 원할 때
GitHub Copilot — 코드 에디터 안에서 직접 HTML을 수정하며 섬세하게 다듬고 싶을 때
둘 다 함께 — Claude로 초안을 잡고, Copilot으로 VS Code에서 세부 조정 (가장 강력!)

환경 설정

시작 전 준비 — 딱 3단계

처음 한 번만 설정하면 됩니다. 10분이면 충분합니다.

1
VS Code 설치
Microsoft에서 무료로 제공하는 코드 에디터입니다. HTML 파일을 직접 수정하고 미리볼 수 있습니다.
설치 주소
https://code.visualstudio.com/ → Download 버튼 클릭 → 설치
2
GitHub 계정 만들기 (무료)
Copilot은 GitHub 계정으로 로그인합니다. 이메일만 있으면 무료로 가입할 수 있으며, 무료 플랜으로 Copilot을 바로 사용할 수 있습니다.
가입 주소
https://github.com/ → Sign Up → 이메일 입력 → 가입 완료
3
VS Code에 Copilot 확장 설치
VS Code를 열고, 왼쪽 사이드바의 Extensions 아이콘을 클릭한 뒤 "GitHub Copilot"을 검색하여 설치합니다.
Ctrl + Shift + X → Extensions 패널 열기
Ctrl + Shift + I → Copilot Chat 열기
실전 가이드

HTML 시각화 자료 만들기

VS Code + Copilot으로 아름다운 HTML 리포트를 만드는 실전 워크플로우입니다.

A
새 HTML 파일 만들기
VS Code에서 빈 파일을 만들고 .html 확장자로 저장합니다.
단축키
Ctrl+N → 새 파일 → Ctrl+Shift+S → 파일명.html 로 저장
B
Copilot Chat에 요청하기
Ctrl + Shift + I로 Copilot Chat을 열고, 원하는 내용을 한국어로 설명합니다. 구체적일수록 결과가 좋습니다.
✅ 좋은 요청 예시
"녹색과 흰색 컬러를 사용해서, 월별 매출 데이터를 막대 차트로 보여주는 HTML 대시보드를 만들어줘. 제목은 '2026 상반기 매출 현황'이고, 상단에 총 매출 숫자도 크게 보여줘."
❌ 애매한 요청 예시
"대시보드 만들어줘" — 너무 막연하면 평범한 결과가 나옵니다.
C
코드 붙여넣기 & 미리보기
Copilot이 생성한 코드를 html 파일에 붙여넣고 파일을 저장합니다. 브라우저에서 파일을 열어 결과를 확인합니다.
브라우저로 열기
방법 1: 파일 탐색기에서 .html 파일 더블클릭 방법 2: VS Code에서 Live Preview 확장 설치 후 에디터에서 바로 미리보기
D
대화로 수정하기
마음에 안 드는 부분은 Copilot Chat에 다시 요청합니다. "이 부분을 ~로 바꿔줘"라고 하면 됩니다.
수정 요청 예시
"배경 색을 흰색에서 연한 크림색(#FFFAEB)으로 바꿔줘"
추가 요청 예시
"차트 아래에 데이터 요약 표도 추가해줘. 월, 매출, 전월대비 증감을 컬럼으로 구성해줘."
프롬프트 전략

잘 작동하는 요청 패턴

Copilot에게 요청할 때 이 4가지 요소를 포함하면 훨씬 원하는 결과를 얻을 수 있습니다.

① 목적
무엇을 만들 건지

"~하는 HTML 파일을 만들어줘"

대시보드 / 보고서 / 인포그래픽 / 발표 자료 / 비교표 등 형식을 명확히 지정합니다.

② 내용
어떤 데이터/정보가 들어갈지

"데이터는 ~이야 / ~을 보여줘"

실제 숫자, 항목 이름, 표시할 내용을 직접 넣어주면 그대로 코드에 반영됩니다.

③ 디자인
색상·스타일 지정

"~색을 써줘 / 모던한 느낌으로"

색 이름(파랑, 크림색 등), 분위기(미니멀, 컬러풀, 다크 테마 등), 폰트까지 지정 가능합니다.

실전 프롬프트 완성 예시

이렇게 요청해보세요
"단일 HTML 파일로 제작해줘. 2026년 상반기 광주지역 장비 설치 현황 보고서야.

내용은 총 설치 건수 127건, 고장 접수 23건, 처리 완료 19건이야. 월별 설치 건수도 막대 차트로 보여줘 (1월:18, 2월:22, 3월:25, 4월:21, 5월:24, 6월:17).

색상은 진한 초록(#105742)과 크림색(#FFFAEB) 위주로, 깔끔하고 전문적인 느낌으로 만들어줘. Chart.js 라이브러리 사용해줘."
✓ 형식 지정 ✓ 실제 데이터 포함 ✓ 색상 지정 ✓ 라이브러리 명시

코드 설명 요청

오류 수정 요청
"차트가 안 보여. 왜 그런지 찾아서 고쳐줘"
스타일 변경 요청
"전체 폰트를 Noto Sans KR로 바꾸고 모바일에서도 잘 보이게 해줘"
초보자 팁

이것만 알면 됩니다

두려워 말고 일단 해보기
잘못된 코드가 나와도 괜찮습니다. Ctrl+Z로 되돌리거나 "고쳐줘"라고 다시 요청하면 됩니다. 컴퓨터가 망가지지 않습니다.
결과가 이상할 땐 더 구체적으로
"다시 해줘"보다 "제목 폰트를 더 크게, 최소 40px로 해줘"처럼 구체적으로 말하면 원하는 결과에 가까워집니다.
완성된 파일은 백업해두기
마음에 드는 결과가 나오면 파일을 다른 이름으로 저장해두세요. 나중에 수정하다가 망쳐도 복구할 수 있습니다.
Claude와 Copilot 병행 활용
Claude로 전체 구조와 초안을 만들고, VS Code + Copilot으로 세부 데이터와 스타일을 다듬으면 최고의 결과물이 나옵니다.
