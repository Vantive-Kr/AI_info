시작하기: 4단계 가이드

초보자는 “작게 요청하고, 결과를 확인하고, 조금씩 수정하는 방식”이 가장 안전합니다.

1

접속하기

🖥️

ChatGPT 같은 AI 도구에 접속하고 로그인합니다. 별도 코덱스 설치가 필요한 경우보다, 대화형으로 바로 시작하는 경우가 많습니다.

2

요청하기

✍️

예: “반응형 포트폴리오 웹페이지를 HTML과 CSS로 만들어줘.” 원하는 스타일, 기능, 색상, 버튼도 함께 적습니다.

3

코드 확인하기

🧩

생성된 코드를 바로 복사하지 말고, 제목·버튼·섹션·스크립트가 어떤 역할인지 설명을 같이 받는 것이 좋습니다.

4

실행·수정하기

🚀

브라우저나 개발 도구에서 실행한 뒤, “버튼 색을 검정으로”, “모바일에서 더 보기 좋게”처럼 다시 수정 요청합니다.

추천 워크플로우

실무에서도 많이 쓰는 흐름을 초보자 버전으로 단순화하면 아래와 같습니다.

💡

1. 아이디어 정리

무엇을 만들지 먼저 한 문장으로 정리합니다. 예: “회사 소개용 웹페이지”

</>

2. 코드 요청

필요한 언어와 스타일을 함께 적습니다. 예: HTML, CSS, 반응형, 미니멀 디자인

🔍

3. 테스트와 수정

실행해 보고 어색한 부분을 다시 요청합니다. 예: “폰 화면에서 글자가 너무 커.”

📦

4. 완성 및 배포

웹은 서버나 호스팅에 올리고, 앱은 개발 도구에서 빌드해 배포합니다.

초보자를 위한 팁

처음 사용할 때 가장 중요한 습관들입니다.

🎯

구체적으로 요청하기

“웹페이지 만들어줘”보다 “검정 배경, 흰 글씨, 소개 섹션 3개가 있는 웹페이지”가 훨씬 좋은 결과를 줍니다.

🧱

작은 단위로 나누기

한 번에 전부 만들기보다, 헤더 → 본문 → 버튼 → 반응형 순서로 나누면 수정이 쉬워집니다.

🛠️

에러 메시지 그대로 보여주기

실패했을 때는 에러 문장을 그대로 붙여 넣으면 원인 분석과 해결 제안이 훨씬 정확해집니다.

📘

설명도 함께 요청하기

“이 코드가 무슨 뜻인지 줄마다 설명해줘”라고 요청하면 실력이 훨씬 빨리 늘어납니다.

자주 묻는 질문

초보자가 가장 많이 궁금해하는 내용입니다.

코덱스는 프로그래밍을 몰라도 쓸 수 있나요?

네. 처음에는 자연어로 요청하고, 생성된 결과를 조금씩 수정하는 방식으로 충분히 시작할 수 있습니다.

HTML과 앱 제작도 가능한가요?

가능합니다. HTML/CSS/JS 웹페이지, Flutter·React Native 같은 앱 예제, 간단한 서버 코드까지 요청할 수 있습니다.

생성된 코드는 바로 써도 되나요?

바로 쓰기보다는 꼭 실행해 보고, 보안·오류·디자인·기능을 확인한 뒤 수정하는 것이 좋습니다.

어떤 식으로 질문하는 게 좋나요?

목적, 언어, 스타일, 필요한 기능, 화면 수, 원하는 느낌을 함께 적으면 결과 품질이 좋아집니다.
