Claude Cowork 기능 가이드

스킬 · 커넥터 · 플러그인

Claude를 더 강력하게 확장하는 세 가지 핵심 기능을 초보자도 쉽게 이해할 수 있도록 정리한 가이드입니다.

스킬 (Skill) 커넥터 (Connector) 플러그인 (Plugin)
핵심 개념

세 가지 기능이란?

Claude는 기본 대화 기능 외에도 스킬, 커넥터, 플러그인을 통해 자신만의 AI 워크플로우를 구성할 수 있습니다.

스킬 (Skill)
Skill

Claude에게 특정 작업 방식을 가르치는 지침서입니다. "이렇게 해줘"라고 미리 정의해두면, Claude가 매번 같은 방식으로 작업합니다.

  • 반복 작업을 일관되게 처리 (예: 주간 보고서 작성, 이메일 브리핑)
  • 마크다운 파일(.md)로 작성된 프롬프트 집합
  • 팀 전체가 동일한 방식으로 Claude를 사용 가능
  • 업무에 맞춤화된 출력 형식과 스타일 유지
커넥터 (Connector)
Connector / MCP

Claude가 외부 서비스(Gmail, Slack, Notion 등)와 실제로 연결되는 통로입니다. 읽고, 쓰고, 전송하는 등 실제 행동이 가능해집니다.

  • Gmail · Outlook으로 이메일 작성 및 발송
  • Slack · Teams에 메시지 전송
  • Google Drive · OneDrive 파일 읽기/쓰기
  • MCP(Model Context Protocol) 표준 기반
플러그인 (Plugin)
Plugin

스킬 + 커넥터를 하나로 묶은 완성된 패키지입니다. 설치 한 번으로 특정 업무 영역 전체를 Claude에게 추가합니다.

  • 마켓플레이스에서 설치 가능한 확장 기능
  • 영업/마케팅/데이터 분석 등 업무별 패키지
  • 조직 전체에 배포 및 공유 가능
  • .plugin 파일로 패키징 및 배포
구조 이해

세 기능의 관계

플러그인은 스킬과 커넥터를 담는 그릇입니다. 마치 스마트폰 앱처럼, 설치하면 모든 기능이 함께 제공됩니다.

🔌 커넥터도 있을 때

📦 플러그인으로 묶으면

동료에게 공유하거나 팀 전체에 배포할 수 있습니다. 설치 한 번으로 동일한 스킬+커넥터 환경이 구성됩니다.

직접 만들기 ①

스킬 만드는 방법

스킬은 Markdown 파일로 작성합니다. Claude에게 "이런 상황에서 이렇게 해줘"라고 구체적으로 적으면 됩니다.

1
스킬 폴더 구조 만들기
플러그인 내 skills/ 폴더 아래에 스킬 이름으로 폴더를 만듭니다.
skills/ └── my-weekly-report/ └── SKILL.md
2
SKILL.md 파일 작성
스킬의 이름, 목적, 실행 방법, 출력 형식을 Markdown으로 작성합니다.
# 주간 보고서 스킬 ## 언제 사용하나요? "주간 보고서 작성해줘"라고 할 때 ## 작성 방식 1. 이번 주 완료한 작업 목록 2. 다음 주 계획 3. 이슈 및 요청 사항 ## 출력 형식 - 한국어로 작성 - 표 형식 사용 - 200자 이내 요약 포함
3
플러그인에 등록
plugin.json에 스킬 정보를 추가하면 Claude가 인식합니다.
"skills": [ { "name": "my-weekly-report", "description": "주간 보고서 작성" } ]
4
테스트 및 개선
Claude에게 요청해보고, 출력이 원하는 대로 나오지 않으면 SKILL.md를 수정합니다.

💡 좋은 스킬의 조건

  • ✓ 언제 사용할지 명확하게 설명
  • ✓ 출력 형식과 길이를 구체적으로 지정
  • ✓ 예시 입력/출력 포함 (few-shot)
  • ✓ 단계별 지침보다 목표 위주로 작성

🤖 skill-creator로 자동 생성

직접 작성이 어렵다면, Claude에게 skill-creator 스킬을 실행해달라고 하세요. Claude와 대화하며 스킬을 자동으로 만들어줍니다.

"skill-creator 스킬 실행해서
주간 보고서 스킬 만들어줘"
직접 만들기 ②

커넥터 연결하는 방법

커넥터는 MCP(Model Context Protocol) 서버를 통해 외부 서비스와 연결합니다. 기존 커넥터를 활성화하거나 직접 만들 수 있습니다.

방법 1 · 마켓플레이스 커넥터 활성화
Cowork 설정에서 Gmail, Outlook, Slack 등 공식 커넥터를 OAuth 인증으로 바로 연결
⭐ 가장 쉬움
방법 2 · MCP 서버 직접 구성
Node.js 또는 Python으로 MCP 서버를 작성하고 plugin.json에 등록하여 사내 시스템과 연결
⭐⭐⭐ 개발 필요
방법 3 · 오픈소스 MCP 서버 활용
GitHub에 공개된 MCP 서버(Anthropic 공식, 커뮤니티 제작)를 설치해서 바로 사용
⭐⭐ 보통

📋 plugin.json 커넥터 등록 예시

"mcpServers": { "outlook": { "command": "npx", "args": ["-y", "@anthropic/mcp-server-outlook"], "env": { "OAUTH_TOKEN": "your-token" } } }
직접 만들기 ③

플러그인 만들고 배포하기

스킬과 커넥터를 완성했다면, 플러그인으로 묶어 팀과 공유하거나 마켓플레이스에 배포할 수 있습니다.

📁 플러그인 파일 구조

my-plugin/
├── plugin.json ← 메타데이터
├── README.md ← 설명서
└── skills/
├── weekly-report/
└── SKILL.md
└── email-briefing/
└── SKILL.md

plugin.json 핵심 내용

{ "name": "vantive-weekly", "version": "1.0.0", "description": "주간 보고 자동화", "skills": [...], "mcpServers": {...} }

🚀 배포 방법

  • 1. 폴더를 압축하여 .plugin 파일로 만들기
  • 2. Cowork → 플러그인 관리 → 파일 업로드
  • 3. 팀원에게 .plugin 파일 공유 또는 URL 배포

🤖 자동 생성 추천

"create-cowork-plugin 스킬 실행해줘"라고 하면 Claude가 대화 방식으로 플러그인 전체를 자동 생성해드립니다.

초보자 가이드

처음 시작하는 분께

어디서부터 시작해야 할지 모르겠다면, 아래 순서대로 따라해보세요.

Step 1 · 기존 스킬 활용 먼저
이미 설치된 스킬(docx, xlsx, pptx 등)을 먼저 사용해보세요. "xlsx 스킬 실행해줘"처럼 직접 요청하면 됩니다.
Step 2 · 마켓플레이스 플러그인 설치
Sales, Marketing, Finance 등 업무별 플러그인을 설치하면 해당 도메인 스킬 수십 개가 한번에 추가됩니다.
Step 3 · 커넥터 연결
Cowork 설정에서 Gmail이나 Outlook을 연결하면 Claude가 실제 이메일을 발송할 수 있게 됩니다.
Step 4 · 나만의 스킬 제작
반복 업무가 생기면 "skill-creator 스킬로 [업무명] 스킬 만들어줘"라고 요청해 자동 생성해보세요.

한 줄 요약

스킬은 Claude에게 방법을 가르치고, 커넥터는 실제 손이 되어주며, 플러그인은 이 모두를 팀과 나눕니다.
